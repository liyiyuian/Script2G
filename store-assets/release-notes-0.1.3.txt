EvenScriptable 0.1.3 — release notes (package com.liyiyuian.evenscriptable, SDK 0.0.16)

HUB CHANGELOG (paste into the version's changelog field)
------------------------------------------------------------------
First version: add JavaScript scripts on your phone and run them on your glasses. Many Scriptable scripts work as they are; long output scrolls smoothly; web requests go through an optional bridge on your own computer. Comes with one example, Time of day.
Requires Even Realities app 2.2.10 or later.
------------------------------------------------------------------

FULL LOG (0.1.3 replaces 0.1.0–0.1.2, which were never published)
- New in 0.1.3:
  - Long output scrolls smoothly: the glasses scroll the text themselves (no redraw per swipe), with
    the script's name fixed above it. Output longer than about 950 characters is split into parts
    ("part 1 of 3"); the next part opens at the end of a part, or from the menu (tap then hold →
    Next part / Previous part).
  - Import from computer opens a clear panel ("Import from your computer", with Close), and a
    script shows "Imported ✓" after you import it.
  - A slow storage call at startup can no longer leave the glasses blank.
- 0.1.2: display name EvenScriptable. 0.1.1: one example script, "Time of day", on first launch.
- 0.1.0: scripts added on the phone run in a Web Worker with Scriptable-like APIs (ListWidget → text,
  Alert/UITable → a list, Request → the bridge, Keychain and FileManager → the Even app's storage,
  args.widgetParameter → the script's Parameter); live output; every gesture answers; a script that
  blocks for 15 s is stopped; system menu with favourite scripts; optional self-hosted bridge
  (bridge/install.sh, Tailscale-only, password).
