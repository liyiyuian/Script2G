EvenScriptable 0.1.4 — release notes (package com.liyiyuian.evenscriptable, SDK 0.0.16)

HUB CHANGELOG (paste into the version's changelog field)
------------------------------------------------------------------
First version: add JavaScript scripts on your phone and run them on your glasses. Many Scriptable scripts work as they are; long output scrolls smoothly; starred scripts sit at the top; web requests go through an optional bridge on your own computer. Comes with one example, Time of day.
Requires Even Realities app 2.2.10 or later.
------------------------------------------------------------------

FULL LOG (0.1.4 replaces 0.1.0–0.1.3, which were private builds only)
- New in 0.1.4:
  - Phone page in three tabs (Scripts, Computer, Keychain). Script cards: Run / Edit / More (★ Star,
    Open at launch, Delete with a second tap). The last result shows under the script you ran.
    Computer shows Connected / Not set up / Can't reach, with numbered setup steps and Save and test.
    Keychain values are masked (Show/Hide). The editor opens full screen with Cancel / Save.
  - Starred scripts come first on the glasses list and on the phone, and are in the glasses menu.
- 0.1.3: smooth scrolling (the glasses scroll the text themselves; long output in parts, Next/Previous
  part in the menu), a clear Import from computer panel, startup that tolerates slow storage.
- 0.1.2: display name EvenScriptable. 0.1.1: one example script, "Time of day", on first launch.
- 0.1.0: scripts added on the phone run in a Web Worker with Scriptable-like APIs (ListWidget → text,
  Alert/UITable → a list, Request → the bridge, Keychain and FileManager → the Even app's storage,
  args.widgetParameter → the script's Parameter); live output; every gesture answers; a script that
  blocks for 15 s is stopped; optional self-hosted bridge (bridge/install.sh, Tailscale-only, password).

Self-hosted bridge: no change needed for 0.1.4 (re-running install.sh upgrades it and keeps your settings).
